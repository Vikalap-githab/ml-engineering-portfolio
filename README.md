# Портфолио Machine Learning Engineer

Сборник проектов в рамках программы «Machine Learning Engineer».  
Цель: создание надежных end-to-end решений — от очистки сырых данных и проектирования витрин (Data Marts) до генерации признаков (Feature Engineering) и построения предиктивных моделей.

## Проекты в репозитории
- **01_SQL_EDA_Fantasy_Game**: Исследовательский анализ монетизации и генерация поведенческих признаков игроков (ARPU, средний чек, частота покупок) для последующего ML-моделирования.
- **02_Data_Marts_Design** *(в процессе)*: Проектирование оптимизированных витрин данных для ускорения обучения моделей и работы аналитиков.
- **03_Python_ML_Modeling** *(в процессе)*: Полный цикл построения ML-модели (от EDA и подготовки данных до оценки метрик качества).

## Инженерный подход
- **Качество данных (Data Quality):** Строгая обработка пропусков, аномалий и выбросов перед любым моделированием (принцип Garbage In, Garbage Out).
- **Feature Engineering:** Акцент на создании информативных признаков, которые часто важнее выбора самого алгоритма.
- **Чистота и масштабируемость кода:** Использование CTE, модульность и осмысленный нейминг для легкой передачи кода в продакшн.
- **Фокус на бизнес-метриках:** Любая модель или витрина должна решать конкретную задачу (удержание пользователей, прогнозирование LTV, балансировка экономики).
